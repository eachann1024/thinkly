# 修改笔记

## 适用

- 改本轮明确授权页面的已有内容：润色、精简、总结、重命名，或增删指定段落。

## 执行

- 对每个目标先调用 `readPage`（明确 notebookId 和 pageId），校验归属；来源引用本身没有修改授权。
- 只改用户要求改动的部分，未触及段落保持原样。
- 局部修改用 `search_replace`：`oldString` 从 readPage 原文原样复制；追加时取文末稳定片段。
- 仅在整页重写、空页填满，或 `search_replace` 无法表达时用 `edit`。
- 仅重命名：`edit` 带新 `title`，`markdown` 用原文且不改正文。
- 只处理授权目标，不把结果写到新页面；多页修改一次提交计划，每项绑定自己的 target.notebookId 和 pageId。

## 完成

- 提交计划后停止，等待审批。
- 用户执行后用一句话概括实际修改。
- 失败时说明原因，不连续重试。
