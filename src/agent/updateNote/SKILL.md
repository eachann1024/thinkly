# 修改笔记

## 适用

- 按用户要求修改已有页面，包括优化格式、整理、润色、精简、总结、重命名，或增删指定段落；可以跨文件、目录和笔记本。

## 执行

- 对每个目标先调用 `readPage`（明确 notebookId 和 pageId），校验归属；用户要求修改的来源引用可直接作为目标，无需重新授权。
- 只改用户要求改动的部分，未触及段落保持原样。
- 局部修改用 `search_replace`：`oldString` 从 readPage 原文原样复制；追加时取文末稳定片段。
- 仅在整页重写、空页填满，或 `search_replace` 无法表达时用 `edit`。
- 整页整理或重写时，不额外生成与页面标题同名的一级标题（`# 标题`）；原文正文没有这一行就不要补上，原有标题与其他章节标题保留。
- 仅重命名：`edit` 带新 `title`，`markdown` 用原文且不改正文。
- 只处理用户要求的目标，不把结果写到新页面；多页修改一次提交计划，每项绑定自己的 target.notebookId 和 pageId。

## 完成

- 提交计划后停止，等待审批。
- 用户执行后用一句话概括实际修改。
- 失败时说明原因，不连续重试。
