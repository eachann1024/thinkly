# 删除笔记

## 适用

- 用户明确要求删除页面，或完成其他操作后删除来源页。

## 执行

- 只删除明确指定的页面；目标不清时先 `listPages` 或 `searchNotes`，再 `readPage` 核对。
- 按笔记本分组生成 `delete` 操作，一次提交计划；每项 target.notebookId 必须与所有 pageIds 的真实归属一致。
- 不按相似标题猜测。
- 删除父页面会连同子页面一起删除。
- 新建汇总后删除来源时，不要把新页面加入删除列表。

## 限制

- 不删除文件夹、锁定页面或未获得本轮修改授权的页面；跨笔记本目标必须明确授权。
- 不执行永久删除。

## 完成

- 提交计划后停止，等待审批。
