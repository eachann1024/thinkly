# 侧栏图标选择

- 交付范围：四套「本地、大纲、搜索、设置」图标，每种图标有空心与实心两种状态；先在 HTML 选择，选定后再修改主应用。
- 入口：打开 `index.html`；也可在本目录执行 `python3 -m http.server 8951 --bind 127.0.0.1`，访问 `http://127.0.0.1:8951/`。
- 操作：点击任意侧栏入口，同步比较四套选中状态；切换深浅主题及 20 / 24 / 28 px；点击「原图」查看 ChatGPT 位图；点击「选这套」保存预览选择。
- 本地选择：仅写入当前浏览器的 `goose-sidebar-icon-preview-v1`；存储不可用时仍能预览，不读写笔记或应用设置。
- 来源：用户提供侧栏截图，经本机 ChatGPT 的 `GPT-6 / High` 生成四张 1774 × 887 PNG；SVG 由同一对话继续生成，用于实际 HTML 图标渲染，属于原图风格的矢量续作。
- 生成记录：`prompt.txt` 为出图提示词，`vector-prompt.txt` 为矢量提示词，`chatgpt-vectors.txt` 保存矢量完整回复；四张 `set-*-raw.png` 为下载原图，未经修改。
- 代码：`icon-sets.js` 保存四套图标的 SVG 元素；`preview.js` 负责状态、原图弹窗及预览选择；`preview.css` 负责布局及明暗主题。
- 运行：无新增依赖、外部字体或网络请求；本页为独立设计预览，不进入应用入口或构建产物。
