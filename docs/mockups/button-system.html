哪些统一，哪些保留专用反馈

范围优化方式保留约束
文字按钮主操作、白键、灰键、透明、文字五级材质；危险操作独立语义色。保留 variant / size / contentStyle、业务事件与热区。
图标与编辑器悬停轻底，按下内凹；常驻状态保持安静。24 / 28 / 32px 图标按钮，26px 编辑器控件。
导航、标签与选择当前主题的选中轮廓，选中与瞬时按压分开。保留单标签无常驻底色、已有分段与页面结构。
菜单、列表与内容轻底色反馈；不把整行内容做成凸起实体按钮。保留无分割线菜单、行高、正文排版与键盘导航。
加载、禁用与语义文字可读、加载宽度稳定，成功绿与危险红分别保留。不改变取消、重试、停止、确认及业务数据流。
系统窗口与拖拽保留系统尺寸与专用光标，不应用凸起材质。不改变窗口能力、拖动手势、缩放边缘。

扫描范围

检索原生 button、共享按钮、编辑器包装、菜单项、选择控件、触发包装与 click / pointer 入口；额外核对共享样式和 Toast 配方调用。

是主要按钮中含尺寸、背景、边框或场景 class 的候选数量，属于静态规则筛选，需逐项判断，不能视为已确认冲突。

实施入口

先统一共享配方，再逐项处理场景样式覆盖。

  • control-recipes.ts：现有 variant 与 context 配方。
  • button.tsx / icon-button.tsx：共享语义与 DOM 属性。
  • control-tokens.css / control-states.css：尺寸、状态与动效。
  • editor/ui/button.tsx：编辑器继承与 preserve 布局。
  • workspace-accent-outline.css / toast/*：专用选中和语义覆盖。
本轮交付设计预览与扫描清单，应用实现尚未变更。“当前样式”仅复现共享配方，不是桌面宿主截图；浏览器交互演示不代表 Electron、uTools 或系统窗口功能已经验收。按钮材质是本页候选例外，其余布局、密度与设计约束沿用 DESIGN.md。
