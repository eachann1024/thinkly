# 精准轮廓设计预览

用户已选定 B：多标签选中与导航沿用列表选中边框的强调色，单文档名称栏仅编辑时强调，保留现有结构、圆角、密度与交互链路。此目录为独立设计预览；真实应用实现与验证另行记录。

在仓库根目录运行：

```sh
python3 -m http.server 4178 --bind 127.0.0.1 --directory docs/design/accent-theme-preview
```

打开 `http://127.0.0.1:4178/`，也可直接打开本目录的 `index.html`。
支持 `?theme=ocean|iris|pine|coral|rose|grape|mono|amber|wheat&mode=light|dark`；旧方案参数会被移除，只显示已选设计。

## 范围与状态

- 已删除未选方案、方案比较导航、全局方向键切换、额外按钮/开关/单选/输入演示及相关入口；主题与明暗检查保留在产品壳外。
- 列表保留 30px 可见行、2px 间隔、14px 字、8px 圆角及 1px 选中边框；标签保持 1 个铺满、2–3 个等分、4 个以上横向滚动。
- 未选中项 hover/pressed 使用中性反馈；selected 边框和弱底在移入、移出、按下时保持，不把 hover 变成选中。选中标签按下仅有内部中性反馈，不改变外围轮廓。
- 单文档名称栏默认与 hover 保持中性；点击后编辑态才显示强调色。展示与输入共享字体、行高、内边距及尺寸，失焦/Enter 提交、Escape 取消；多标签选中样式不变。
- 键盘焦点与 selected 分离，标签焦点环向内绘制以避开滚动容器裁切；Tab、方向键/Home/End、Delete 后相邻焦点保留。禁用控件不响应 hover/pressed。
- 系统减弱动态效果会关闭颜色过渡；不增加新动画。语义状态色独立，深色恢复主题色相，背景保持中性深灰。
- 示例内容仅存页面内存；主题与明暗写入当前 URL，不读取或修改应用数据、设置与持久化。

页面下方保留完整八步实施路径、消费者分类、状态/持久化/跨窗口范围、颜色职责与研究来源。
