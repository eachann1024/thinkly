## 设计方向

保留现有网格，以轻薄主题填色和独立工具栏表达选区。浅色选区随当前强调色，深色默认采用低饱和通用蓝 `#8caedc`，可切换为“跟随主题”；正文仍用正常文本色，选区轮廓独立表达范围。

## 正式接入建议

- 增加 `--goose-table-selection-fill`、`--goose-table-selection-border`、`--goose-table-selection-active`、`--goose-table-selection-inactive`，避免改动文本原生选区、侧栏或其他共享控件。
- 填色使用透明叠层，保留自定义单元格颜色、表头语义和文字色；不使用文字反白掩盖对比问题。
- 沿用现有 Selection / Decoration，只改变视图样式；取消选择后完整恢复原有底色，历史、保存、复制与导出不带选区装饰。
- 工具栏只对 `cellGrid` 增加避让规则，保留正文、跨块、跨表、图片、链接与独立速记路径。
- 为宽度受限的分栏、200% 缩放和触屏保留横向滚动；工具栏压缩低频操作，不能遮住当前格与表头。
- 本原型的列比例和自然换行用于说明方向，正式实现继续尊重已有列宽、合并单元格与内容属性。

## 原型范围

- 动态工具栏：正文、标题、列表、引用、表格范围、格内文字、图片、代码、链接、附件和多块选区共用同一组件；操作、尺寸、菜单、焦点和明暗状态一致。窄窗口将低频操作收入“更多”。
- 交互状态：格式混合、只读、失焦、无选区、复制中 / 成功 / 失败、本页撤销、颜色、链接、JSON 格式化、图片与附件预览；AI 对话支持本地完整交互，不连接模型服务。
- 已实现：九种主题色，浅色 / 深色 / 跟随系统，深色通用蓝 / 跟随主题，单格、多格、整行、整列、无选区，鼠标拖选，Shift 扩选，方向键、Enter 编辑、Esc 取消、全选、复制，格式切换、添加行、原有底色、失焦与重置。
- 未实现：ProseMirror / BlockNote 集成，合并单元格，真实笔记持久化，完整撤销历史，真实模型请求及 AI 会话持久化，行列排序，列扩展，跨表选择，导出。
- 后续最小验收：浏览器人工操作明暗与强调色、主题轻染布局、拖选及键盘操作，检查窄窗没有页面横向溢出，选区取消后恢复原有底色；侧栏按下节设计约定检查，不编写、不运行测试用例。

## 选区到对话的交互闭环

- 表格范围、格内文字不再显示重复的“编辑内容”图标；双击单元格或按 Enter 仍可编辑。正文、标题、列表、引用、表格与代码中的“加入对话”直接添加引用，支持 `⌘/Ctrl + Shift + U`，没有中转复制弹层。
- 引用包含来源、内容快照与原位置，按来源页和文本去重；单行引用可预览完整内容、定位原文或移除，支持一次携带多个引用。
- 输入指令后按 Enter 或点击发送，Shift + Enter 换行，输入法确认不会误发；上一轮的引用可继续使用，草稿和历史在收起、重开面板时保留。
- “本地演示”使用确定性的离线规则，支持整理成清单、统一空格、转为大写和“替换为：内容”；不支持的指令明确提示调整，不伪装成模型推理结果，不发送网络请求。
- 回复有生成中、停止、完成、失败状态；可选择“模拟失败一次”体验重试。停止会取消后续更新，重试沿用同一轮的引用与指令，不重复添加用户消息。
- 完成后可编辑回复、复制、插入原文下方或替换原选区；多引用可选择写入位置。跨格替换必须保留原有行列数，文字范围只替换选中的字符，跨块文字范围保留插入方式。
- 写入使用引用时保存的位置，不受后来切换选区或场景影响；写入前核对原文快照，遇到内容变化、来源失效或只读时显示原因，不静默覆盖。
- 写入进入本页同一撤销记录；回复旁的“撤销写入”仅在该写入是最近操作时生效，避免撤销后来手动编辑的内容。全局“重置演示”同时清空对话、引用、回复、待完成回调与写入内容。
- 对话由 `ai-source.js`（快照、定位与写入）、`ai-response.js`（离线回复状态）、`ai-view.js`（渲染）、`ai-menu.js`（引用预览与会话菜单）、`ai-chat.js`（交互）和 `ai-chat.css` 组成；AI 使用应用主题色，深色表格选区可独立采用通用蓝。

生产接入时继续沿用 `AddToChatButton.tsx` → `selectionQuoteData.ts` / `selectionQuoteDom.ts` 的引用数据和去重规则；本原型仅对齐其选区入口，不能证明真实模型请求、笔记保存或跨重启恢复可用。
