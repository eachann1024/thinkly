## 功能对应（官网首屏）

- **块编辑**：输入 `/` 或 `、` 唤起插入菜单，拼音搜索（`biaoge` → 表格）；待办、表格、公式、Mermaid 流程图；拖动内容块调整顺序。
- **AI 对话**：空白段落按空格唤起行内 AI，`⌘J` 打开 AI 面板；选中文字点浮动工具栏「AI」；跨笔记批量修改先给差异再审批；AI 默认关闭。
- **速记小窗**：`Alt + N` 任意软件唤出置顶小窗，`Alt + 1–5` 五张便签；失焦不消失，草稿自动保存，一键存入笔记。
- **分屏**：左右／上下任意组合，最多四格，一边翻资料一边写。
- **分享图**：导出长图，另有 Markdown、HTML、PDF、Word。
- **历史**：停笔自动存版本，最多 50 个，里程碑永久保留，还原前先存一版。

## 动效词典

- 文本：`spring({ damping: 200, stiffness: 120, mass: 0.6 })`，Y +40 → 0，逐词 stagger 3 帧。
- 卡片：`cubic-bezier(0.22, 1, 0.36, 1)`，18 帧，scale 0.92 → 1。
- 底色：`cubic-bezier(0.65, 0, 0.35, 1)`，12 帧交叉淡化（黑场与品牌卡为硬切）。
- 飞入：X 位移 + scale，18 帧，不旋转入场。
- 落下／印章：`spring({ damping: 12, stiffness: 300 })`，2° 过冲后回正。
- 人物：只用升起／位移（整数像素）或切帧，不做 scale；换姿势切帧无补间，每段驻留 ≥ 20 帧。
- 列表滚动：linear，56px/s。
- 摄像机全程静止，只动元素。

## 质量保证

- 点阵数据：`node scripts/gen-sprites.mjs` 把素材按 4px 网点重新半调，生成 `src/sprites.ts`（依赖仓库根的 `sharp`）。
- 静帧：`npm run stills`，覆盖 9 镜首尾帧、中点帧与末帧。
- 联系表：`npm run contact-sheet` → `qa/contact-sheet.jpg`（3×3）。
- 逐项核查：衬线斜体是否被裁切、圆角是否露白边、半调网点是否起摩尔纹、强调色占比、相邻镜头主运动是否重复、转场是否露边。
- 整片：H.264 / yuv420p / CRF 18 / `+faststart`。
