## 动效词典

所有时长以帧为单位；缓动只用三次贝塞尔，弹簧只用阻尼比 ζ 描述（`damping = 2ζ√(k·m)`）。

| 名称 | 定义 | 用途 |
| --- | --- | --- |
| `EASE_GLIDE` | `cubic-bezier(0.45, 0, 0.2, 1)` | 长镜头推拉摇移 |
| `EASE_SOFT` | `cubic-bezier(0.33, 0, 0.15, 1)` | 缓推、色温溶解 |
| `EASE_TEXT_IN` | `cubic-bezier(0.16, 1, 0.3, 1)` | 字幕纸片出现 |
| `EASE_EXIT` | `cubic-bezier(0.5, 0, 0.75, 0)` | 字幕与道具退场 |
| `EASE_BREEZE` | `cubic-bezier(0.37, 0, 0.63, 1)` | 云、叶、萤火的风吹路径 |
| `SPRING_TEXT` | ζ = 0.9，k = 120，m = 1 | 字幕上浮 24px 落定，几乎无回弹 |
| `SPRING_KEY` | ζ = 0.6，k = 180，m = 1 | 速记键帽落下，轻快一弹 |
| `SPRING_LOGO` | ζ = 0.85，k = 100，m = 1 | 结尾标志落定 |

字幕节奏：进入 18 帧，停留至少 75 帧，退出 12 帧；同一时刻画面上最多一组字幕。

## 禁用的默认效果

- 线性插值（未指定缓动的 `interpolate`），以及 CSS `ease`、`ease-in-out` 等关键字缓动。
- Remotion `spring()` 默认参数（damping 10，会明显回弹），以及任何回弹超过 8% 的文字动画。
- `@remotion/transitions` 预设的 slide、wipe、flip、clock-wipe，以及所有镜头之间统一的透明度交叉淡化。
- 黑场溶解、纯黑帧、霓虹或发光、彩色投影、渐变大字。
- 打字机效果、逐字级联、文字从左侧滑入、旋转、3D 翻转、甩镜、缩放模糊、动态模糊滤镜。
- 每个镜头同方向的 Ken Burns；同一镜头内多于一个主运动。
- 常驻脉冲、循环呼吸、闪烁光斑。

## 质量保证

1. 静帧：在 `0, 100, 210, 330, 450, 560, 680, 800, 925, 1040, 1170, 1290, 1417, 1560, 1680, 1790` 帧截图（`remotion still`）。
2. 联系表：16 张静帧按 4×4 拼成 `qa/contact-sheet.jpg`，逐格检查构图、字幕可读性、转场是否露边、颜色是否跳变。
3. 修复：每发现一个问题，记录在下方「修复记录」，改完重截对应静帧并更新联系表。
4. 完整渲染：H.264，`yuv420p`，CRF 自调使成片 ≤ 10 MB，`-movflags +faststart`，输出到 `public/intro/goose-intro.mp4`，另导出第 0 帧为 `public/intro/goose-intro-poster.jpg`。
