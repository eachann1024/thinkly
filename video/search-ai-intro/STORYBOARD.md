## 功能对应

- 全局搜索：`Mod+K` 唤起；标题、正文、拼音检索；当前／所有笔记本范围；仅标题；最佳匹配／最近编辑；最近访问；命中高亮与摘要。
- 搜索内 AI：结果区顶部「询问 AI」；本地预检索后由只读代理作答；引用编号与来源笔记；`Esc` 返回；`⌘↵` 进入 AI 面板继续。
- 只读边界：`searchNotes`、`readPage`、`listPages`、`searchWeb`、`readWebPage`，不修改笔记。
- AI 面板：整理为待办、写入审批、继续追问。

## 动效词典

- 文本：`spring({ damping: 200, stiffness: 120, mass: 0.6 })`，Y +40 → 0，逐词 stagger 3 帧。
- 卡片：`cubic-bezier(0.22, 1, 0.36, 1)`，18 帧，scale 0.92 → 1。
- 底色：`cubic-bezier(0.65, 0, 0.35, 1)`，12 帧交叉淡化。
- 印章：`spring({ damping: 12, stiffness: 300 })`，2° 过冲。
- 人物换姿势：切帧无补间，每姿势 ≥ 20 帧。
- 列表滚动：linear，56px/s。
- 摄像机全程静止。

## 质量保证

- 静帧：`npm run stills`，覆盖每个镜头首尾帧、转场帧与尾帧。
- 联系表：`npm run contact-sheet` → `qa/contact-sheet.jpg`（3×3）。
- 人工核查：衬线斜体裁切、圆角白边、半调摩尔纹、强调色占比、相邻镜头主运动重复、转场露边。
- 整片：H.264 / yuv420p / CRF 18 / faststart。
