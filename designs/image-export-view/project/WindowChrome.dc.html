拖动区域
标题与空白处：可拖动 按钮、输入框、分段：不拖动
Linux 用指针拖动，双击空白处最大化；macOS 与 Windows 走系统拖动区域。

每个独立窗口都具备

来自现有主窗口、速记和资源清理窗口的能力，统一下沉到一个窗口工厂里。

跟随浅色 / 深色

窗口底色在创建时就按主题设好，打开不闪白；切换主题实时同步。bindWindowAppearance

⌘W / Ctrl+W 关闭

和标签页一致的关闭快捷键；确认类小窗口另外支持 Esc。bindCloseTabAccelerator

同类只开一个

再次打开时把已有窗口拉到前面，不重复创建。

记住位置与大小

按窗口类型保存；换了显示器时拉回可见区域，并有最小尺寸。workAreaNear

字号、缩放、语言一致

界面字号、页面缩放和语言沿用主窗口设置，改动后各窗口同步。

与主窗口联动

在独立窗口里点笔记，会在主窗口打开并前置，独立窗口留着继续看。

确认类是子窗口

重置、删除这类确认挂在主窗口下、居中弹出并阻断主窗口，不会被压到后面。

收紧权限

禁止跳转、新开窗口和权限请求，链接一律交给系统浏览器。

关闭后释放

关闭即回收进程资源；进行中的任务（如反思生成）在主窗口继续跑。

窗口菜单与 Dock

窗口名进入系统“窗口”菜单，可用 ⌘` 在 Thinkly 的窗口之间切换。
