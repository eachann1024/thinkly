全局弹窗清单

扫描 src/ 下所有 Dialog / DialogShell 的使用处，共 10 个弹窗，外加 1 个仍用系统标题栏的窗口。

独立窗口子窗口 · 阻断主窗口只换标题栏
界面入口改为默认 / 最小尺寸说明
反思
ReflectionDialog		侧边栏底部「反思」独立窗口1100×760 / 760×560范围切换和刷新移到标题栏；点笔记在主窗口打开，反思窗口保留。
生成图片
image-export-theme-selector		页面菜单 · 选区菜单独立窗口1280×800 / 900×600见本稿第一行 A / B / C 三个方案。
恢复稿
RecoveryDraftsDialog		启动检测到未保存内容独立窗口960×680 / 720×480改成左列表右预览，不再翻页。
更新日志
AppUpdateDialog		检测到新版本独立窗口600×680 / 480×420下载进度在窗口里走，关掉也不打断下载。
配置 AI 写作助手
AIFeatureNotice		首次使用 AI独立窗口640×680 / 520×520保存后自动关闭，主窗口的 AI 面板立即可用。
全屏预览
FullscreenPreview		图表、图示放大独立窗口跟随内容 / 480×360缩放控件放进标题栏，可拖到另一块屏幕对照着写。
编辑笔记本
NotebookEditDialog		笔记本切换器 · 编辑子窗口560×680 固定删除 / 移除的二次确认在同一窗口内切换，不再叠一层。
重置设置
renderSettingsResetDialog		设置 › 数据子窗口460×400 固定输入确认短语；Esc 取消。
数据操作确认
SettingsDataPanel		设置 › 数据 · 导入 / 恢复子窗口460×自适应和重置设置共用确认窗口模板。
选区引用
SelectionQuotePreview		AI 输入框里的引用子窗口480×420 / 360×280「打开来源笔记」后自动关闭。
清理资源
asset-maintenance		设置 › 数据只换标题栏1000×720 / 760×540已经是独立窗口，但还是系统标题栏，统一换成自定义标题栏。

不在范围内：设置（主窗口内整屏切换，非弹窗）、全局搜索与速记（已是独立浮窗）、首次引导、图片灯箱，以及下拉菜单、右键菜单、浮层、提示和通知这类贴着触发点出现的轻量浮层。
