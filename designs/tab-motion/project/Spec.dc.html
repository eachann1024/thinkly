时序规格

统一曲线 cubic-bezier(.2, 0, 0, 1)；单次操作 280ms 内结束；系统开启「减少动态效果」时全部 0ms。

槽位宽度 / 位置 标题与 × 透明度 选中底色与描边
0 60 90 150 220 280 ms
新建（N → N+1）
新槽位从 0 展开，其余槽位同步收窄 · 220 选中态移到新标签 · 150 新标题淡入，右移 4px 落位 · 80→220
关闭未选中
标题与 × 淡出 · 90 槽位连同间距收拢到 0，邻居补位 · 60→280
关闭选中
标题与 × 淡出 · 90 选中交给右邻（无则左邻）· 150 槽位收拢，邻居补位 · 60→280
1 → 2
单标签从占满收窄到一半，新标签展开 · 220 多标签底色与描边淡入 · 150 新标题淡入 · 80→220
2 → 1（占满）
标题与 × 淡出 · 90 剩余标签占满剩余空间 · 60→280 选中底色淡出为单标签样式 · 60→210
批量关闭（其他 / 左侧 / 右侧）
全部同时淡出 · 90 全部同时收拢，不逐个级联 · 60→280
3 ↔ 4（等分 ↔ 滚动）
等分宽度与 155px 之间同步过渡（新建时）· 220 同上（关闭时，跟随收拢）· 60→280

不再拍快照

标签栏退出 View Transition（去掉标签上的 view-transition-name，关闭不再包 runWithPresence），改由槽位自身过渡，文字永远按真实布局渲染。

先标记，再移除

关闭时先把标签标成「离场」并立刻移交选中，280ms 后再从列表删除；新建时先以 0 宽挂载，下一帧再给目标宽度。

标签栏宽度过渡是例外

DESIGN.md 禁止过渡布局属性；标签栏高度固定、只影响一行，建议在规范中为槽位宽度单列例外。
