这个演示回答的问题：选中文本后，三种列表怎么互相切换？

选中一段或多段，在提醒事项、无序列表、有序列表之间来回转换。不新增快捷键。 用左右箭头或底部切换条看三个版本。点正文选块，Shift 点连续多选。

周末行程

棕色底是已选中；浅灰底表示这类块会被跳过（页面标题、代码）。嵌套子项会跟着父项保留。

共同规则

  • 只改块类型，不走 Markdown 往返，不拆 children。
  • 光标在单块、或选中多块，都能转。
  • 页面标题、代码、媒体、分割线跳过。
  • 勾选只在提醒事项之间保留；转出待办后勾选丢掉。
  • 编号连续项交给现有 start 规范化。
  • 不新增快捷键，也不加「高级」二级菜单。
